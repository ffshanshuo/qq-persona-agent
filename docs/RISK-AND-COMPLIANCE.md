# 合规与风险：用个人号挂第三方客户端会发生什么

这份文档来自一次**真实事故**，不是理论推演。**用主号之前请先读完。**

## 一、事故经过

某天晚上，用个人 QQ 号（主号）通过 NapCat 注入运行了几天之后：

- 手机 QQ 弹出「你的账号身份验证信息已失效，部分功能暂时使用受限」；
- NapCat 的快速登录凭据失效（`QQLogin/CheckLoginStatus` 返回 `waiting_qrcode`，`GetQuickLoginQQ` 返回空）；
- 此后**每一次自动重登都会加重风控**，最终只能由号主在手机官方客户端里重新做人脸/短信验证。

## 二、真正的原因（和很多人的猜测不一样）

不是「主动发了一条消息」。腾讯盯的是三类信号，按权重从高到低：

| 信号 | 具体表现 | 本项目的对策 |
| --- | --- | --- |
| **客户端/协议指纹** | 非官方客户端的登录凭据、加密字段、上报的设备信息 | 无法根本规避；只能用低价值小号，并保持环境稳定 |
| **登录环境异常** | 频繁上下线、短时间内多地 IP、反复重登 | `risk.js`：每日登录 ≤3、最小间隔 10 分钟、30 分钟内两次掉线自动冷却 6 小时、登录失败直接冷却 12 小时 |
| **行为异常** | 批量加好友、群发、模板化重复、深夜高频主动私聊 | 不做群发/批量私聊；想念调度有冷却与每日上限；被动回复不限额（真人不会因为回得快被封） |

**关键结论**：风险是**账号级、持续性**的，不按单条消息线性计价。但动作类型确实影响触发概率：

```
被动回复（reply）  <<  主动找人（proactive）  <  发说说/改资料（qzone/profile）  <  加好友/群发（friend）
```

所以 `risk.js` 把动作分级，默认**只放行被动回复**。想开放主动动作必须显式改 `config/risk.json`。

## 三、三条可选路线

| 路线 | 身份 | 能力 | 封号风险 | 适合 |
| --- | --- | --- | --- | --- |
| **A. 手机官方 QQ + adb/无障碍自动化** | 就是这个号 | 几乎全部（真机操作，包括主动私聊、改资料、发说说） | 低（仍是官方客户端） | 需要完整能力、能接受慢（每次操作 0.5–2s） |
| **B. QQ 开放平台官方机器人** | 独立 bot 身份（AppID） | 群/频道/单聊消息、被动与主动消息（有额度、需用户先互动）；**不能**发空间、改资料、主动私聊陌生人 | 零（官方审核制） | 长期稳定运营、不需要「像真人」以外的操作 |
| **C. NapCat / 第三方客户端注入** | 就是这个号 | 全部（本项目当前形态） | 高（有实证） | 个人自用、小号、只做被动回复 |

本项目把「人格 / 记忆 / 分寸 / 表情」这些**通道无关**的部分做成了独立层，所以 A/B/C 可以互换：换掉 `scripts/qq.js` 与 `auto-reply.js` 的收发层，其余十几层原样复用。B 路线已有 `phone.js` 的镜像思路可参考（把「发送」抽成函数即可）。

## 四、如果坚持用个人号（最低限度纪律）

1. **小号优先**。不要用绑定了重要社交关系的主号。
2. **只做被动回复**。`config/risk.json` 的 `allowProactiveOnClient` 保持 `false`。
3. **环境稳定**：同一台机器、同一个 IP、别频繁重启。项目自带的 watchdog 有闸门，别把它改成无脑重启。
4. **掉线就停**。连续两次探活失败后应当进入冷却并等人工确认，而不是反复重登——重登是加速封禁的最快方式。
5. **不群发、不批量加好友、不深夜高频私聊**。这些是最容易被判成营销号的模式。
6. **留退路**：号主要能随时在手机上完成验证。

## 五、法律与条款

- 本项目的目的是**学习与研究**：研究「对话智能体的记忆、情绪与应答如何接近真人」。
- 使用第三方客户端可能违反腾讯的服务条款；后果（包括账号被限制、封禁）由使用者自行承担。
- 不要用它做：诈骗、冒充他人、骚扰、批量营销、爬取他人隐私。
- 仓库**不包含**任何账号、聊天记录、好友列表、表情图片素材；示例配置全部脱敏。

## 六、开源分发时的脱敏清单

发布/分享本项目时，请检查这些位置（`scripts/` 里已尽量用环境变量）：

- [ ] `scripts/gw.token` / `ob11.token` / `api-key`（**绝不入库**，`.gitignore` 已覆盖）
- [ ] `config/autoreply.json` 的 `selfId`、`private.allowList`、`group.allowList`
- [ ] `config/longing.json` 的 `muteList`
- [ ] `logs/`（上下文、记忆图、痕迹里全是真实对话）
- [ ] `assets/stickers/`（下载来的表情有版权风险）
- [ ] 代码注释里的真实 QQ 号、群号、手机号、绝对路径、主机名

本仓库生成时用的是脚本化替换（`_opensrc` 系列正则），并在 `grep -rl` 校验为空之后才提交。
